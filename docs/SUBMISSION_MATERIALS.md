# 提交材料建议

本文档用于准备 AI / Agent 项目申请材料。建议保持材料真实、克制，不夸大功能和自动化程度。

## 推荐提交内容

- GitHub 仓库链接：优先提交当前仓库首页链接。
- App 运行截图：建议使用真实设备或 Android 模拟器截图。
- Android Studio 构建成功截图：可展示 Gradle 任务成功完成的界面。
- AI / Agent 对话截图：可展示需求拆解、代码分析、Bug 排查或文档整理过程。
- GitHub README 截图：可展示项目简介、功能、技术栈、AI / Agent 辅助开发流程和构建说明。
- Release 页面：建议发布 `v0.1.0-alpha`，并在 Release Notes 中说明这是早期版本。

## 建议截图页面

- 首页
- 学习计时
- 科目管理
- 学习统计
- 每日复盘
- AI 总结
- 设置页面

## 敏感信息处理

提交材料前请检查并打码：

- API Key
- 邮箱
- 手机号
- 账单编号
- 账号 ID
- 支付二维码
- 本地路径中不希望公开的个人信息

不要上传包含真实密钥、签名证书、付款码或隐私数据的截图。

## Release 建议

建议创建一个 `v0.1.0-alpha` Release：

- 标题：`v0.1.0-alpha`
- 说明：早期可运行版本，包含学习计时、科目管理、记录统计、每日复盘和 AI 总结配置。
- APK：如需上传安装包，请通过 GitHub Releases 附件上传，不要提交到代码仓库。
