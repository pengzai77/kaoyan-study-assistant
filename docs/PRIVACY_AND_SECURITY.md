# 隐私与安全

本文档记录项目在隐私和敏感信息管理方面的基本约定。

## 用户数据

- 用户学习数据默认存储在本地设备。
- 学习记录、每日复盘、目标设置等内容不应在未经用户确认的情况下上传到第三方服务。
- 如后续引入云同步，应明确说明同步范围、存储位置和用户控制方式。

## API Key

- API Key 不应硬编码到项目代码中。
- 项目不提供默认第三方模型服务 Key。
- 第三方模型服务由用户自行配置服务地址、模型名和 Key。
- 使用第三方模型服务前，应自行确认对应服务的隐私政策和计费规则。

## 本地配置和签名文件

以下内容不应提交到代码仓库：

- `local.properties`
- `.env`
- `*.jks`
- `*.keystore`
- `*.p12`
- APK / AAB 构建产物
- 支付二维码或其他个人敏感图片

## 发布前检查

发布 APK 前建议检查：

- 仓库中是否包含 API Key、账号信息或本地路径。
- 安装包中是否包含不应公开的测试配置。
- Release 附件是否只包含需要分发的 APK，而不包含签名证书。
